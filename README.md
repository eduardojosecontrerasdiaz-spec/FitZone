# FitZone

Proyecto final integrador del programa ADSO. FitZone es una aplicación web responsive para gestionar un gimnasio.

## Tecnologías
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Tailwind CSS
- LocalStorage

## Funciones principales
- Navegación entre páginas.
- Planes y registro de membresía.
- Gestión CRUD de usuarios, entrenadores y clases.
- Buscador de usuarios.
- Modo oscuro.
- Contadores dinámicos.
- Barra de progreso.
- Consumo de JSONPlaceholder y visualización de datos en Dashboard.
- Validación de campos, correo y contraseñas.
- Bootstrap: Navbar, Cards, Carousel, Modal, Toast, Accordion, Offcanvas, Formularios, Botones y Grid.
- Sección completa del Dashboard construida con Tailwind CSS.

## Cómo ejecutar
1. Abrir `index.html` en un navegador.
2. Para la API pública se necesita conexión a Internet.
3. Los datos creados en el Dashboard se guardan en LocalStorage del navegador.

## Importante para la sustentación
El proyecto usa JavaScript básico: variables, funciones, eventos, DOM, LocalStorage, `fetch`, condicionales y arreglos. No requiere frameworks de JavaScript.
