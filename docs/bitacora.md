# Bitácora de Desarrollo - FitZone

## Introducción

Esta bitácora registra el proceso de desarrollo del proyecto FitZone, desde la creación del repositorio hasta la implementación de las funcionalidades JavaScript y la organización final del proyecto.

El desarrollo se realizó de manera progresiva, comenzando por la configuración y estructura del proyecto, continuando con la construcción de las páginas HTML, el diseño visual y finalmente la implementación de la lógica JavaScript.

---

# Día 1 - Creación del repositorio

## Actividades realizadas

* Creación del repositorio del proyecto FitZone.
* Configuración inicial del repositorio.
* Preparación del proyecto para comenzar el desarrollo.

## Resultado

Se estableció el repositorio que serviría como base para almacenar y controlar las diferentes versiones del proyecto.

---

# Día 2 - Estructura inicial

## Actividades realizadas

* Creación de la estructura inicial del proyecto.
* Creación de las carpetas principales.
* Creación de los archivos iniciales.
* Organización inicial de los recursos HTML, CSS, JavaScript y documentación.

## Resultado

Se obtuvo una estructura base que permitió comenzar el desarrollo de las diferentes partes de FitZone.

---

# Día 3 - Desarrollo de HTML

## Actividades realizadas

* Desarrollo de la estructura HTML de las páginas.
* Organización del contenido de las diferentes secciones.
* Desarrollo inicial de las páginas correspondientes al proyecto.
* Implementación inicial de estilos en las páginas que utilizarían Bootstrap y Tailwind CSS.
* Preparación de las páginas para continuar con el desarrollo visual.

## Resultado

Las principales páginas del proyecto quedaron estructuradas y se estableció la base visual inicial.

---

# Día 4 - Mañana: Organización del CSS

## Actividades realizadas

Durante la mañana se creó la estructura principal para los estilos personalizados.

Se crearon:

* `variables.css`
* `style.css`
* `responsive.css`

## Resultado

Los estilos del proyecto quedaron organizados y separados por responsabilidad.

Esto permitió trabajar posteriormente en la identidad visual y en la adaptación responsive.

---

# Día 4 - Tarde: Diseño y ampliación del proyecto

## Actividades realizadas

Durante la tarde se continuó con el diseño visual de FitZone.

Se realizaron las siguientes actividades:

* Finalización del diseño de las páginas HTML.
* Incorporación de nuevas páginas.
* Incorporación de imágenes.
* Modificación del fondo.
* Ajustes de colores.
* Mejoras visuales de las tarjetas.
* Ajustes de botones.
* Mejoras generales de la interfaz.
* Organización visual de las diferentes secciones.
* Adaptación del diseño para mantener una identidad visual coherente.

## Resultado

El proyecto pasó de tener una estructura inicial a contar con una interfaz visual más completa y coherente con la temática de un gimnasio.

---

# Día 4 - Noche/Madrugada: JavaScript

## Actividades realizadas

Durante la noche y madrugada se desarrolló la lógica JavaScript del proyecto.

Se implementaron los diferentes archivos JavaScript necesarios para agregar funcionalidad a las páginas.

Entre los archivos desarrollados se encuentran:

* `app.js`
* `storage.js`
* `crud.js`
* `validation.js`
* `api.js`
* `darkmode.js`
* `planes.js`
* `registro.js`
* `clases.js`
* `detalle-clase.js`
* `entrenadores.js`
* `perfil-entrenador.js`

## Funcionalidades desarrolladas

* Manipulación del DOM.
* Eventos.
* Validaciones.
* LocalStorage.
* CRUD.
* Gestión de usuarios.
* Gestión de entrenadores.
* Gestión de clases.
* Modo oscuro.
* Buscador.
* Consumo de API pública.
* Interacciones de planes.
* Registro.
* Detalle de clases.
* Perfiles de entrenadores.

## Resultado

Se completó la incorporación de la lógica JavaScript y el proyecto pasó de ser principalmente visual a contar con funcionalidades dinámicas.
