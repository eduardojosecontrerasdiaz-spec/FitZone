# FitZone — Rediseño visual V2

## Objetivo
Mejorar la estructura visual sin reemplazar el contenido del HTML.

## Se conserva
- Textos.
- Menú.
- Secciones.
- Tarjetas.
- Formularios.
- Botones.
- Información de planes.
- Información de entrenadores.
- Lógica JavaScript.

## Se mejora
- Paleta: blanco + azul + verde.
- Hero de inicio con imagen protagonista centrada.
- Espaciado y jerarquía.
- Tarjetas.
- Botones.
- Formularios.
- Dashboard.
- Footer.
- Responsive.
- Armonización visual de las páginas que usan Bootstrap/Tailwind.

## Nota técnica
Se dejaron las páginas existentes y se actuó principalmente sobre CSS. Las rutas absolutas de imágenes que empiezan por `C:\Users\...` siguen presentes en algunos HTML originales y conviene corregirlas en una segunda pasada para que funcionen en cualquier computador.
